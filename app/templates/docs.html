Документация магазина

Покупка

  1. Найдите товар по названию или категории. Нажмите на название, чтобы открыть карточку.
  2. Добавьте товары в корзину и измените количество. Flask проверяет цены при оформлении.
  3. Подтвердите демо-заказ. Браузер сохранит его номер и сумму.

Маршруты API

МетодПутьРезультат
GET/api/categoriesКатегории товаров
GET/api/productsКаталог с параметрами q, category и sort (default, low, high)
GET/api/products/notebookКарточка товара по идентификатору
POST/api/cartПроверка позиций и расчёт стоимости
POST/api/ordersДемо-заказ. Ответ 201 содержит номер заказа и сумму

Пример корзины

Оба POST-маршрута принимают JSON с позициями. Количество на позицию — от 1 до 99. Две тетради стоят 158 ₽.

{"items":[{"id":"notebook","quantity":2}]}

Планы JMeter

smoke.jmx проверяет путь от каталога до заказа. load.jmx позволяет менять число пользователей, длительность, метод и путь запроса.

Параметр каталога delay_ms=250 добавляет задержку. Параметр заказа error_rate=0.15 включает демонстрационные ответы 503.

Метрики

Prometheus читает /metrics. В Grafana сравните RPS, p95 и долю ответов 5xx для каталога и оформления заказа. Проверка Flask.
