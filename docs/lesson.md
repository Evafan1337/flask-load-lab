# Практикум JMeter для интернет-магазина

Проверьте путь покупателя и сопоставьте клиентские замеры JMeter с серверными метриками каталога и оформления заказа.

## 1. Smoke

[Запустите стенд](../README.md#быстрый-запуск-в-docker) и выполните команду запуска smoke.

```sh
docker compose run --rm --build jmeter smoke
```

План [smoke.jmx](../jmeter/smoke.jmx) проверяет состояние сервера, категории, каталог, карточку тетради, расчёт корзины и демо-заказ. Первые пять ответов должны вернуть HTTP 200, заказ — HTTP 201. Для корзины из двух тетрадей по 79 ₽ ожидается сумма 158 ₽. Откройте HTML-отчёт по пути из терминала.

## 2. Нагрузочные сценарии

Запускайте [load.jmx](../jmeter/load.jmx) последовательно с одинаковым числом виртуальных покупателей и одинаковой длительностью.

```sh
docker compose run --rm jmeter load -JUSERS=10 -JDURATION=30
docker compose run --rm jmeter load -JUSERS=10 -JDURATION=30 "-JPATH=/api/products?delay_ms=250"
docker compose run --rm jmeter load -JUSERS=10 -JDURATION=30 -JMETHOD=POST "-JPATH=/api/orders?error_rate=0.15"
```

Первый запуск читает каталог. Второй добавляет 250 мс к обработке каталога. Третий повторяет демо-заказ двух тетрадей с заданной вероятностью ответа HTTP 503. Успешный заказ в этом сценарии отвечает HTTP 201. Фактическая доля ответов 503 зависит от выборки.

В режиме Docker задайте `-JUSERS` от 1 до 50 и `-JDURATION` от 1 до 300 секунд. Если нужен короткий контрольный прогон, начните с 2 пользователей и 10 секунд.

| Сценарий | RPS JMeter | p95 JMeter, мс | Ошибки JMeter, % | Что видно в Grafana |
| --- | ---: | ---: | ---: | --- |
| Каталог | | | | |
| Каталог, задержка 250 мс | | | | |
| Заказ, вероятность 503 — 15% | | | | |

В [Grafana магазина](http://127.0.0.1:3000/d/flask-load-lab) выберите период тестов. Для анализа каталога и заказа используйте фильтр маршрутов.

1. Сравните RPS и p95 двух прогонов каталога. Почему при одинаковом числе покупателей RPS может снизиться после добавления задержки?
2. Отдельно посчитайте скорость успешных заказов и скорость всех ответов. Как влияют 503 на обе величины?
3. Сопоставьте p95 JMeter с p95 Flask. JMeter измеряет запрос со стороны клиента, а серверная гистограмма показывает время внутри Flask. Учитывайте выбранное окно и очередь ожидания.

## Локальный JMeter

Установите Java 17 и Apache JMeter 5.6.3. На Windows команда называется `jmeter.bat`. В графическом интерфейсе откройте `jmeter/smoke.jmx` и проверьте короткий запуск через **View Results Tree**. Цель по умолчанию — `127.0.0.1:5000`.

Для замеров используйте запуск без GUI. Команда для Linux или macOS выполняется из корня репозитория.

```sh
jmeter -n -t jmeter/load.jmx -JUSERS=10 -JDURATION=30 "-JPATH=/api/products?delay_ms=250" -l reports/local-catalog-slow.jtl -j reports/local-catalog-slow.log -e -o reports/local-catalog-slow-html
```

При каждом запуске указывайте новое имя JTL и новый каталог HTML.
