# Подготовка занятия

1. Откройте магазин и страницу документации `/docs`. Проверьте каталог, карточку товара и оформление демо-заказа.
2. Запустите [smoke JMeter](lesson.md#1-smoke). Проверьте 6 успешных запросов и сохранение HTML-отчёта.
3. Откройте [Grafana магазина](http://127.0.0.1:3000/d/flask-load-lab) и [цели Prometheus](http://127.0.0.1:9090/targets). Цель `flask` должна быть UP.
4. Согласуйте с группой длительность и число виртуальных покупателей. Запускайте сценарии последовательно, сохраняйте HTML-отчёты и сравнивайте одинаковые интервалы графиков.
5. [Дополнительное занятие с Locust](locust-lesson.md) можно провести после практикума JMeter.

## Если графики пусты

- Проверьте выбранные период и маршрут. Для скорости запросов нужны хотя бы два сбора Prometheus.
- Проверьте адрес магазина. С хоста это `http://127.0.0.1:5000`, внутри сети Compose — `http://flask:5000`.
- В итогах заказов учитывайте HTTP 201 и HTTP 503 раздельно. При включённой вероятности 503 откройте раздел ошибок HTML-отчёта.
- В Locust для браузерного сценария выберите `locust`, для автоматического прогона — `locust_headless`.
- По завершении остановите процессы или контейнеры по [инструкции](../README.md#остановка).
