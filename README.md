# Flask Load Lab · JMeter и Grafana

Учебный стенд для сравнения пропускной способности, времени ответа и HTTP-ошибок. **JMeter** отправляет запросы в **Flask**, **Prometheus** собирает серверные метрики, **Grafana** показывает их на готовом дашборде.

## Быстрый запуск

На Windows, Linux или macOS нужен запущенный Docker с Compose. В GitHub откройте репозиторий под аккаунтом, которому преподаватель выдал доступ, и выберите **Code → Download ZIP**. Можно также клонировать репозиторий:

```sh
git clone https://github.com/Evafan1337/flask-load-lab.git
cd flask-load-lab
```

Из корня проекта выполните в PowerShell или терминале:

```sh
docker compose up --build -d --wait
docker compose run --rm --build jmeter smoke
```

При первой сборке Docker скачает базовые образы и Apache JMeter 5.6.3. Java и JMeter отдельно устанавливать не требуется. Smoke проверяет четыре маршрута. В конце команда печатает путь к HTML-отчёту. Если хотя бы одна проверка провалилась, команда вернёт ненулевой код.

| Что открыть | Адрес |
| --- | --- |
| Учебное приложение | [127.0.0.1:5000](http://127.0.0.1:5000/) |
| Проверка Flask | [127.0.0.1:5000/health](http://127.0.0.1:5000/health) |
| Метрики сервера в Grafana | [Дашборд Flask](http://127.0.0.1:3000/d/flask-load-lab) |
| Сбор метрик | [Цели Prometheus](http://127.0.0.1:9090/targets) |

У цели `flask` должен появиться статус **UP**. Grafana открывается для просмотра без входа. Порты стенда доступны на компьютере, где запущен Docker.

## Первый замер

Выполните по очереди два прогона. Первый запрашивает быстрый маршрут, второй добавляет 250 мс работы обработчика.

```sh
docker compose run --rm jmeter load -JUSERS=10 -JDURATION=30
docker compose run --rm jmeter load -JUSERS=10 -JDURATION=30 "-JPATH=/api/slow?delay_ms=250"
```

В Grafana выберите последние 15 минут и обновление каждые 5 секунд. Для построения графиков Prometheus нужны несколько сборов подряд. Сопоставьте RPS и p95 на дашборде с HTML-отчётом из `reports/`. JMeter измеряет полный запрос со стороны клиента, Grafana показывает метрики обработчика Flask.

[Практикум JMeter](docs/lesson.md) включает сценарий с HTTP 503 и вопросы к результатам. В нём также описан запуск плана через графический интерфейс JMeter.

Чтобы остановить стенд и сохранить историю метрик:

```sh
docker compose down
```

Если Docker сообщает о занятом порте, проверьте, свободны ли `5000`, `9090` и `3000`. На Linux, если JMeter не может записать отчёт, задайте в `.env` параметры `LOCAL_UID` и `LOCAL_GID` из команд `id -u` и `id -g`. Пример параметров — в `.env.example`.
