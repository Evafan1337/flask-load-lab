# Интернет-магазин канцтоваров

Учебный проект на Flask. Можно найти товар, открыть его карточку, собрать корзину и оформить демо-заказ. JMeter проверяет те же HTTP-маршруты, Prometheus собирает метрики, Grafana показывает RPS, задержки и ошибки.

## Быстрый запуск в Docker

Нужен Docker с Compose. Склонируйте открытый репозиторий или скачайте ZIP через **Code → Download ZIP**.

```sh
git clone https://github.com/Evafan1337/flask-load-lab.git
cd flask-load-lab
docker compose up --build -d --wait
docker compose run --rm --build jmeter smoke
```

При первой сборке Docker скачает базовые образы и JMeter 5.6.3. Smoke проверяет шесть запросов от каталога до создания заказа. Путь к HTML-отчёту выводится в терминал.

| Что открыть | Адрес |
| --- | --- |
| Магазин и корзина | [127.0.0.1:5000](http://127.0.0.1:5000/) |
| Документация магазина | [Справка и API](http://127.0.0.1:5000/docs) |
| Метрики магазина | [Grafana](http://127.0.0.1:3000/d/flask-load-lab) |
| Сбор метрик | [Цели Prometheus](http://127.0.0.1:9090/targets) |

В Prometheus проверьте статус **UP** у цели `flask`. В Grafana выберите последние 15 минут. Для графиков скорости нужно несколько сборов метрик.

## Запуск в Windows без Docker

Из корня проекта выполните команды PowerShell.

```powershell
.\scripts\Setup-Windows.ps1
.\scripts\Start-Lab.ps1 -OpenBrowser
.\scripts\Status-Lab.ps1
```

Установщик рассчитан на Windows x64. Он скачивает и сверяет контрольные суммы инструментов, затем сохраняет их в каталоге проекта. Магазин, Grafana и Prometheus доступны по тем же адресам. Перед переключением между способами запуска остановите текущий стенд, чтобы освободить порты.

Для нативного прогона подготовьте Java 17 и Apache JMeter 5.6.3. Добавьте JMeter в `PATH` или укажите путь к `jmeter.bat` целиком. Выполните эту команду из корня проекта.

```powershell
$stamp = Get-Date -Format yyyyMMdd-HHmmss
jmeter.bat -n -t .\jmeter\smoke.jmx -l ".\reports\smoke-$stamp.jtl" -j ".\reports\smoke-$stamp.log" -e -o ".\reports\smoke-$stamp-html"
```

Проверьте в HTML-отчёте шесть успешных запросов, включая создание демо-заказа. [Подробности запуска в Windows и необязательный Locust](docs/locust.md)

## Нагрузка в JMeter

В [практикуме](docs/lesson.md) три сценария. Каталог отвечает в обычном режиме и с добавленной задержкой, а оформление демо-заказа моделирует ответы HTTP 503. Сравните RPS, p95 и долю ошибок на дашборде и в отчётах JMeter.

В практикуме используются следующие маршруты.

| Запрос | Назначение |
| --- | --- |
| `GET /api/categories` | Категории товаров |
| `GET /api/products` | Каталог. Параметры `q`, `category` и `sort` задают поиск, фильтр и порядок `default`, `low` или `high`. |
| `GET /api/products/notebook` | Карточка тетради |
| `POST /api/cart` | Расчёт корзины по текущим ценам |
| `POST /api/orders` | Создание демо-заказа, HTTP 201 |

Демо-заказ возвращает номер и итоговую стоимость. Интерфейс сохраняет их в браузере. Учебный сценарий заканчивается показом подтверждения.

## Остановка

Для контейнерного запуска подойдёт команда Compose.

```sh
docker compose down
```

В нативном режиме выполните скрипт остановки.

```powershell
.\scripts\Stop-Lab.ps1
```

Если при запуске занят порт, проверьте `5000`, `9090` и `3000`. Если JMeter в Docker на Linux не может записать отчёт, задайте в `.env` свои `LOCAL_UID` и `LOCAL_GID` из команд `id -u` и `id -g`. Формат переменных приведён в `.env.example`. Сгенерированные отчёты и локальные настройки хранятся в рабочей копии. [Проверки GitHub Actions](https://github.com/Evafan1337/flask-load-lab/actions)
