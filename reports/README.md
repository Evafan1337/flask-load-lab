# Отчёты запусков

`scripts/Run-LoadTest.ps1` сохраняет сюда отдельную папку для каждого запуска:
CSV, HTML и `run.json` с параметрами и результатом. `scripts/Run-Demo.ps1`
последовательно выполняет baseline, slow и errors и создаёт `comparison.json`.
Сгенерированные файлы исключены из Git. Результаты относятся к конкретному
компьютеру и не являются оценкой производительности Flask в целом.
